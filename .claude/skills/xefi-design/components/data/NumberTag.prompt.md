Nombre mis en évidence — un compteur d'éléments, un rang, une quantité, à côté d'un libellé.

```jsx
<NumberTag value={14} tone="brand" size="sm" />
```

`variant="boxed"` encadre le nombre, `"plain"` le laisse nu. Pour un statut nommé, utilisez `Badge` : un nombre seul ne dit pas ce qu'il compte, le libellé voisin doit le dire.
