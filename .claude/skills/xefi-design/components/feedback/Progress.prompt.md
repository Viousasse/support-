Avancement mesurable — barre linéaire pour une progression dans la page, anneau pour un indicateur compact.

```jsx
<Progress value={42} />
<Progress value={42} variant="circular" size={48} showLabel />
```

À n'utiliser que si la progression est réellement connue. Pour une attente de durée inconnue, utilisez un squelette (liste) ou un indicateur d'activité (action ponctuelle).
