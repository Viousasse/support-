Compact contextual row actions — the DailyUp `Btn/*` set. Ghost by default, tone-tinted fill on hover/active.

```jsx
<ContextualButton kind="check" aria-label="Valider" />
<ContextualButton kind="close" aria-label="Refuser" />
<ContextualButton kind="history" active aria-label="Historique" />
<ContextualButton kind="note" aria-label="Commenter" />
<ContextualButton kind="window-close" aria-label="Fermer" />
```

Kinds: check (green) · close (red) · history (amber) · note (neutral) · window-close (neutral).
