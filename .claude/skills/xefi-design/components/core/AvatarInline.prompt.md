Avatar accompagné d'un nom et d'une ligne secondaire — pour une cellule de tableau, un champ d'assignation ou une mention.

```jsx
<AvatarInline initials="LV" name="Lorick Vacher" secondary="CODIR" size="sm" />
```

`reverse` place le texte avant l'avatar, pour un alignement à droite. `secondary` est optionnel : sans lui, le nom se centre verticalement.
